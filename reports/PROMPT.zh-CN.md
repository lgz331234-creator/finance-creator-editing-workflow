# 财经博主剪辑工作流：提示词报告

版本：1.7.0。当前模式确认于2026-09-29；本次分发同步于2026-10-02。完整细则见[ChatCut 直男财经 SOP](../finance-creator-editing-workflow/references/chatcut-zhinan-finance.md)。

## 直接复制调用

```text
使用 $finance-creator-editing-workflow 本机已验证最新版，按 ChatCut 直男财经模式剪辑。
原始口播：填写文件
定稿文案：填写文件
工程及交付目录：填写目录
本片例外：没有则写无

保留本人原录音和定稿原句，只删已授权的口误、重复和多余空白。不重新选题、不改文案、不自动发布。品牌按单词读，字幕与录音有差异时先核对，不猜时码。

先读最新版入口和配置、自己的私有素材绑定，运行 prepare。同工程只保留一个主剪辑任务；恢复只读短状态卡和本次差异。旧工程先备份，按实际差异迁移，保留认可片段与本片例外。

确认真实 ChatCut 连接；用原始素材建立可编辑多轨工程，不以扁平MP4或JSON代替。人物居中，B-roll确实可见，深色低饱和商务风，只有硬切和淡入淡出。默认1080×1920、30fps、85–92秒，五段结构保留完整结尾；时长或脚本结构不匹配时报告具体缺口，不截句凑时长。

中英整句字幕同时显示于安全区，黄底关键词蒙版从左向右按发音揭示。3–20秒无额外动画；40–75秒解释段每8–12秒更新匹配台词的实拍、文字或数据图表。不要自动加入AI视频，不套旧版3秒强制切换或闪白抖动。

本人原声清晰在前，BGM用获准的低沉悬疑商务纯伴奏并轮换；禁止强鼓点和人声歌曲。轨道人声-6dB、BGM-18dB仅为起始增益，按源电平、峰值和实际听审调整，不冒充LUFS或固定响度差。仅反转、关键数字或金句使用短咚，相邻起点至少8秒。本片明确无BGM时不加。

授权封面独立保留：黄字居中、白字清晰、不重叠；不默认插入0.4秒片头。素材来源、许可、对应台词与哈希留在本地证据中，缺真实素材就列缺口。

交付真实多轨工程、带时码的中英字幕和高亮表、逐句素材来源、音效卡点、导出设置、简短设计依据和人工微调清单。执行技术与编辑两遍独立复核；真实听审才标通过。运行check，导出后检查当前文件完整解码、字幕边界、音画同步、峰值及画面；未完成不得声称合格。
```

## 局部修改

```text
继续当前认可工程，仅修改本次指定字幕、BGM、素材或MG。先看短卡、当前工程和差异；保留其余内容。修改声音后重新生成受影响的字幕、高亮、镜头与音效时间。更新七项交付及两轮检查证据，不重复读整段历史。
```

## 使用边界

- 默认以当前本机入口为准；本片明确要求优先。运行中的任务不会自动热更新，恢复时需重新读取。
- 旧拼贴、无真人或无BGM等已认可例外保留；升级规则包不重剪旧片。
- 历史FREYA展示不是新版ChatCut成片验证。技能安装、工具认证、工程完成、成片验收各自记录。
- 工作流与脚本不包含编辑器、付费额度、人像、音色模型或使用权。私有日志、源素材和凭据不得随包公开。
- 短卡记录版本、定稿哈希、基线、差异、最新证据与待办；减少重复输入，不承诺固定节省比例。

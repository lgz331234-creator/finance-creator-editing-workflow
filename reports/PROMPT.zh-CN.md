# 财经博主剪辑工作流：提示词与执行报告

版本：1.0.0｜更新：2026-09-25

## 可直接复制的主提示词

```text
使用 $finance-creator-editing-workflow，按本次最终文案与已认可的参考成片完成剪辑。先核对现有工程、已安装技能和实际可用工具；优先续用已认可工程，选择效果达标且端到端最快的 ChatCut、Remotion 或 FFmpeg 路径。如实说明使用了什么，不把技能安装当作已经完成剪辑。

我给的最终文案是内容基准。不要自行增删观点，不添加机构背书、收益承诺或推广制度。清除我确认的重复口播、录制备注和不自然停顿；保留完整尾句。品牌英文按品牌名自然发音，不逐个字母乱读。每次修改旁白后重新核对字幕和画面。

视觉：1080×1920、30fps。首帧使用我授权的西装人像封面，约0.4秒；品牌／选题大黄字、白色副标题，文字不重叠，导出9:16和3:4两种封面。正文用我已授权的声音；本次FREYA采用西装人像封面后直接进入素材画面，不加真人口播开场。用全屏、与当句意思相关的动态素材，约2–3秒更新视觉主体，单片不重复，不用无关素材充数。真实事件优先用该事件真实素材；照片可适度动起来，不能冒充实拍视频。

屏幕：保留左上两行“视频仅知识分享／不构成投资建议”和低透明度账号字。不要底部“功能逻辑示意·非实际产品界面”等制作说明小字，不加默认进度条或常驻章节条。素材出处和制作证据放交付资料，不在每个画面塞说明；不要借删除小字来制造误导。

声音：本人声音清楚、自然、在前；BGM轻托底，按我这次指定曲目或现有获准音源选择。关键切点搭配多种短音效，不要一直重复同一种。已获授权的本地声音参考留在本地，不自行上传或启用付费生成。

同步：所有句子起止时间必须来自最终写入旁白文件的真实PCM样本数。字幕以当前声音的逐词时码和必要试听对齐，不按文字长度等比例猜时间；不能只修改时长字段。任何旁白裁切、变速、替换后，都重算后续字幕、切镜、音效和总时长。音画以同一时间轴为准。

若要求韩语或日语版：主旁白、主字幕、封面和图内文字都用目标语言，副字幕用英文并紧贴主字幕；数字、日期、比例和观点保持不变。根据目标语言实际声音重新排时间轴，不硬套中文版时长。

交付：按本次明确指定的时长做样片，本次FREYA展示要求60秒；若我已认可样片并明确要求全片，则直接完成全片。交付前检查当前导出的完整解码、异常黑帧／冻帧、首尾语音、字幕切镜、封面裁切和混音人声偏移。有实际听审才说听过。视频、双封面、字幕、文案、素材证据整理到我指定的桌面日期／选题目录；样片和旧版分开，并打开最新预览。

完成后更新私人项目内的本地剪辑日志：版本、批准基线、本次变化、实际工具、输出文件、检查结果、待审项、新偏好和确认经验。仅把明确偏好或核实后的通用经验更新为默认工作流，不因实验覆盖已认可版本。不要自动公开私人日志或素材；上传、定时发布和公开技能包按当前任务的已有授权执行，缺少必要授权时再说明。
```

样片时长由用户本次选择；这里的60秒只用于本次FREYA展示，不是所有视频的固定默认值。已授权的全片不必再等一次批准。身份、曲目、语言和平台以当次输入为准。

## 可直接复制的局部修订提示词

```text
继续已认可版本，只修改我这次指出的问题，保留其余内容、风格与声音。先检查旧结果及当前文件，确认问题位置。若修改旁白，保留正确音频，只重做必要短句；随后按实际PCM样本数重排所有受影响的字幕、镜头和音效。检查新导出，不把旧版验收结果当成新版本通过。保留旧版，交付新版本并更新本地日志。
```

## 执行报告：固定什么，允许调整什么

| 环节 | 必须保持 | 可按本条视频调整 |
| --- | --- | --- |
| 工程 | 已认可基线、源素材和最新授权 | 实际最快可用工具 |
| 文案 | 最终批准内容、完整尾句、准确数字 | 已确认的重复与停顿 |
| 封面 | 本人人像、大黄字、白副标题、双比例清晰 | 题目长度、裁切、字号 |
| 画面 | 全屏、语义对应、素材不重复 | 2–3秒目标内的自然切点 |
| 声音 | 授权声音、清晰人声、真实同步 | BGM和音效相对响度 |
| 字幕 | 实际音频时码、完整意义 | 目标语言分句与换行 |
| 验收 | 当前文件证据，区分机器检查和听审 | 针对具体改动的检查重点 |
| 更新 | 私人日志、明确偏好才升为默认 | 已验证通用经验的公开变更 |

## 已确认的重要教训

曾有一版真实旁白比旧元数据短，片尾累计错位约1.7秒。调整文字、时长标签或增加尾部空白都不能修复根因。应从实际写入的每段PCM样本重新计算整条时间轴，再将当前声音逐词时码映射到字幕和语义切镜。

另一类常见误差是把“最近导出的版本”当成“用户认可的版本”。续作前必须确认批准基线，不能在改一个细节时推翻已经认可的风格。

## 每次交付后的本地记录格式

日志写入私人项目中的 `.local-edit-log/run-log.md`，不要放到公开仓库。

| 字段 | 记录内容 |
| --- | --- |
| 版本与基线 | 日期、当前版本、用户认可的原版本 |
| 本次变化 | 用户明确要求、实际改动及原因 |
| 工具与文件 | 实际工具、当前输出、必要哈希 |
| 验收证据 | 解码、时间轴、字幕、封面、音量及听审状态 |
| 待审 | 未验证、待本人操作或待审看事项 |
| 新偏好 | 用户明确的新规则及适用范围 |
| 经验 | 已确认原因与修正，是否适合升级默认 |

公开版本只包含可复用规则、原创模板和去隐私后的变更记录。原始声音参考、人像源文件、未授权素材、完整项目日志、账号和令牌都不公开；只有本次明确授权展示且已检查的成片和封面，才能独立放入展示区，不随MIT模板授权分发。

每条视频首秒加入本人指定的短综艺音效一次，正文继续轮换音效。参考有人声时先分离，不能混入别人的话；开头音效需随人声压低。音效参考及来源清单留在私人项目，不自动公开原始音频。

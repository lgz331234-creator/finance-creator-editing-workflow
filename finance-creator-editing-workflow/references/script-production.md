# 分阶段口播与分镜生产

这是财经剪辑工作流的脚本生产层。它只负责选题、口播定稿和分镜生成；素材选择、字幕时码、声音处理和导出仍遵守 `SKILL.md` 及其音频、视觉和验收规则。

## 固定顺序

1. 用运营选题提示词生成选题标题，记录已选标题。
2. 用财经文案提示词和已选标题生成口播稿，完成顺口预检并记录定稿编号与摘要。
3. 只传入定稿口播稿和下方主提示词，生成完整分镜脚本。
4. 修改时只传变更片段与必要上下文；不重复输入完整历史。不要自动新建任务，除非用户明确要求。

一次生成阶段只读取本次必要输入，不把历史对话带入。分镜脚本只输出模板内内容，不追加解释，不写时长。

## 主分镜提示词

任务：生成抖音 9:16 短视频分镜脚本，对标直男财经的方法：高密度快切、强反差、反常识钩子和大白话商业口播。不得复制其人物、声音、脚本、水印或素材。

规则：

1. 平均约 3 秒一次转场，禁止长时间固定画面。
2. 台词和贴图一一对应，讲什么配什么素材图。
3. 重点词使用高亮字幕。
4. 转场只用：闪白、硬切、缩放推入、震动闪切。
5. BGM 选紧绷、轻快的财经 BGM，并在项目使用台账中记录。

## 局部修改提示词

只修改指定片段，其余所有内容一字不动保留。仅输出修改完成后的完整脚本，不加解释文字。

```text
修改需求：粘贴你的修改要求
原文脚本：粘贴旧脚本
```

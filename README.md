把已经确认的财经视频标准，变成每次都能调用的剪辑助手。

## 如何调用

本机已安装。在Codex输入：

```text
$finance-creator-editing-workflow
按照我的最新版工作流剪这条视频。沿用已认可的封面和全屏风格，素材跟文案同步，完成后检查并放桌面。
```

也可以说“调用财经剪辑助手”。提供视频或文案、语言与本次修改要求，即可按技能执行。这里的智能体入口是可调用技能，实际剪辑仍需要本机可用的剪辑、配音和导出工具。

其他用户下载仓库，将 `finance-creator-editing-workflow` 文件夹复制到 `~/.codex/skills/`，刷新任务即可调用。请使用自己有权使用的人像、声音和素材。

## 工作流做什么

| 环节 | 标准 |
| --- | --- |
| 封面 | 本人西装图片、大黄字、白副标题，文字不重叠；9:16与3:4两版 |
| 画面 | 正文全屏动态素材，约2–3秒更新视觉主体，匹配当前旁白，不重复充数 |
| 字幕 | 跟随最终真实音频时码；日语、韩语主字幕配紧贴英文副字幕 |
| 声音 | 授权声音突出、BGM轻托底、多种短音效；品牌按单词自然发音 |
| 验收 | 检查当前导出的解码、封面、字幕、音画偏移、首尾与异常黑帧 |
| 更新 | 每次完成记录私人日志；新确认的通用规则同步本地技能与公开版本 |

默认不加底部制作说明小字、进度条或半屏素材框。当前FREYA正文只用声音和素材，首帧保留本人西装封面。用户最新要求优先于历史模板。

每次剪辑的私有日志不会上传。公开仓库只同步可复用规则和本次授权的样片/封面/截图，不包含原始人像、声音参考、声音模型、账号凭据或私密工程。

[MIT许可](LICENSE)适用于原创工作流文档和模板，不覆盖展示媒体、音乐、人物肖像、第三方字体或外部素材。成片展示剪辑效果，不构成对其中项目或财务观点的背书。

把已经确认的财经视频标准，变成每次都能调用的剪辑助手。

当前版本：**1.7.0**。新用户先看[朋友安装与使用说明](朋友安装说明.md)。这是一套剪辑技能和检查规则，实际出片需要可用的剪辑工具及你自己有权使用的素材。

## 如何调用

安装后，在 Codex 输入：

```text
$finance-creator-editing-workflow
按本机最新版 ChatCut 直男财经模式，使用这条原始口播和定稿文案。保留原声和原句，素材与台词同步，交付可编辑多轨工程并完成两轮复核。
```

也可以说“调用财经剪辑助手”。提供原始口播视频、定稿文案、语言与本次修改要求，即可按技能执行。这里的智能体入口是可调用技能，实际剪辑仍需要本机可用的剪辑、配音和导出工具。

其他用户下载仓库，将 `finance-creator-editing-workflow` 文件夹复制到 `~/.codex/skills/`，重新打开 Codex 或开始新任务后调用。Windows 默认目录为 `%USERPROFILE%\.codex\skills\`；设置了 `CODEX_HOME` 时使用它下面的 `skills`。升级前备份旧技能文件夹。请使用自己有权使用的人像、声音和素材。

## 工作流做什么

| 环节 | 标准 |
| --- | --- |
| 封面 | 授权人像、居中黄字与清晰白副标题独立保存；无默认片头封面停留 |
| 文案 | 定稿原句不改写；核对原录音、重复、断句、品牌发音与内容疑点 |
| 画面 | 居中真人或人物窗口，下层 B-roll 真正可见；深色商务风，只用硬切和淡入淡出 |
| 节奏 | 默认五段、85–92秒；40–75秒解释段每8–12秒更新语义信息，保留完整收尾 |
| 字幕 | 中英紧邻整句字幕；关键词黄色蒙版从左向右，按真实发音进入 |
| 声音 | 原录音优先、低音量商务纯伴奏；短咚间隔至少8秒；实际听审，不套固定总响度 |
| 验收 | 技术与编辑两轮复核；工程和导出分别验收，未听审如实保留待办 |
| 上下文 | 同一工程一个主剪辑任务；短状态卡、定稿标识与变更差异交接 |
| 更新 | 本机已验证入口为准；旧工程保留已认可例外，迁移不等于重渲染或发布 |

旧版3秒切换、闪白、默认综艺开场音效及0.4秒封面停留不属于当前默认。旧拼贴模式仅在明确选择或保留已认可工程时使用。单条无 BGM 等例外只对该项目生效；朋友使用自己的素材和声音。短交接不清除聊天历史，也不保证固定 token 节省比例。

## 更新与许可

每次剪辑的私有日志不会上传。公开仓库只同步可复用规则和本次授权的样片/封面/截图，不包含原始人像、声音参考、声音模型、账号凭据或私密工程。

[MIT许可](LICENSE)适用于原创工作流文档和模板，不覆盖展示媒体、音乐、人物肖像、第三方字体或外部素材。成片展示剪辑效果，不构成对其中项目或财务观点的背书。

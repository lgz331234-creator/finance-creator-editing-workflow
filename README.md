# 财经博主剪辑工作流

把已经确认的财经视频标准，变成每次都能调用的剪辑助手。

当前版本：**1.6.0**。新用户先看[朋友安装与使用说明](朋友安装说明.md)。这是一套剪辑技能和检查规则，实际出片需要可用的剪辑工具及你自己有权使用的素材。

## 如何调用

安装后，在 Codex 输入：

```text
$finance-creator-editing-workflow
按照我的最新版工作流剪这条视频。沿用已认可的封面与真人拼贴风格，素材跟文案同步，完成后检查并放桌面。
```

也可以说“调用财经剪辑助手”。提供视频或文案、语言与本次修改要求，即可按技能执行。这里的智能体入口是可调用技能，实际剪辑仍需要本机可用的剪辑、配音和导出工具。

其他用户下载仓库，将 `finance-creator-editing-workflow` 文件夹复制到 `~/.codex/skills/`，重新打开 Codex 或开始新任务后调用。Windows 默认目录为 `%USERPROFILE%\.codex\skills\`；设置了 `CODEX_HOME` 时使用它下面的 `skills`。升级前备份旧技能文件夹。请使用自己有权使用的人像、声音和素材。

## 工作流做什么

| 环节 | 标准 |
| --- | --- |
| 封面 | 创作者授权人像、居中大黄字、清晰白副标题，文字不重叠；9:16与3:4两版 |
| 文案 | 先理解意思、理顺句子，检查重复、断句和品牌读法，再做配音和分镜 |
| 画面 | 真人讲述、小窗、真实贴图与动态素材混合；约2–3秒更新视觉主体，匹配当前旁白 |
| 字幕 | 跟随最终真实音频时码；日语、韩语主字幕配紧贴英文副字幕 |
| 声音 | 授权声音响度一致、BGM按选题轮换、多种短音效；品牌按单词自然发音 |
| 验收 | 两遍复查：技术与声音；内容对应与画面可读性；如实记录未听审项目 |
| 上下文 | 同一工程只设一个主剪辑任务；用短状态卡、定稿文件和变更差异交接 |
| 更新 | 每次完成记录私人日志；新确认的通用规则同步本地技能与公开版本 |

默认不加底部制作说明小字或进度条。单条视频明确要求无 BGM 时，仅该条保留无 BGM。FREYA 展示采用授权西装人像封面和旁白素材模式；朋友使用时替换为自己的账号、人像和声音。用户最新要求优先于历史模板。紧凑交接减少重复输入，不会清除已有聊天历史，也不保证固定 token 节省比例。

## 更新与许可

每次剪辑的私有日志不会上传。公开仓库只同步可复用规则和本次授权的样片/封面/截图，不包含原始人像、声音参考、声音模型、账号凭据或私密工程。

[MIT许可](LICENSE)适用于原创工作流文档和模板，不覆盖展示媒体、音乐、人物肖像、第三方字体或外部素材。成片展示剪辑效果，不构成对其中项目或财务观点的背书。
